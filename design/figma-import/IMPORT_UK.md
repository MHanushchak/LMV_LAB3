# SmartBasket: імпорт оновлених наборів через html.to.design

## Стан

Оновлення 14 листопада 2026: **імпорт у Figma виконано** через офіційний
плагін html.to.design від divRIOTS у браузерному редакторі. MCP-інструменти Figma
в чаті залишалися недоступними, але плагін після дій користувача почав працювати.

Користувацький імпорт головного URL Vercel підтверджено: він містить головну
сторінку англійською, окремі текстові шари та компоненти. Інші маршрути не були
імпортовані цим одиничним імпортом. На Vercel `/sets` ще показує товари всередині
списку, тобто відрізняється від актуального локального списку назв і дій.

Для цього використано повний підготовлений HTML через вкладку **Editor**
на ширині 2100 px. Browse у доступному керуванні не відкривав діалог файлу;
HTML прочитано з локально відкритого документа й вставлено у редактор плагіна.
Службовий елемент браузера вилучено з копії перед імпортом. Оригінальний HTML
залишено без змін. У Figma це текстові, векторні та структурні шари, не PNG.

Окремо на ширині 430 px імпортовано початкові англомовні стани з Vercel:

- [Порожній кошик](https://www.figma.com/design/K9H9c4FOZBzi3KgMQGYYMT/LMV_lab3?node-id=200-4035).
- [Налаштування](https://www.figma.com/design/K9H9c4FOZBzi3KgMQGYYMT/LMV_lab3?node-id=200-4436).

У параметрах використано Use Autolayout, Create styles & variables,
Use existing local styles та HTML layer names. Плагін завершив імпорти з
повідомленням **No missing font**. Перевірено дерево окремих текстів і контейнерів,
Auto Layout фрейму списку, візуальний вигляд усіх чотирьох українських екранів.
Композиція збереглася після перезавантаження редактора.

Для імпортованих з Vercel порівняння й налаштувань виправлено вихід вмісту за
межі телефона: основна область від y=129 до нижньої навігації y=675 має висоту
546 px, Clip content та вертикальне прокручування. Візуально перевірено, що
картки більше не виходять за рамку й не перекривають сусідні секції.
Тимчасовий дубль старого `/sets`, створений агентом під час перевірки, видалено;
користувацький імпорт головної й попередні ідеї збережено.

**Ще не завершено:** явні переходи прототипу між новими українськими екранами,
повний аудит і ручне узгодження всіх стилів/компонентів із Foundation, перевірка
поведінки в Present. Імпортовані hover-варіанти та їхні зв'язки не означають,
що весь користувацький сценарій прототипу налаштовано.

Частково оглянуто структуру: сторінки «03», «01 Концепція», «02 Foundation»;
на сторінці «03» є екрани, Atomic UI kit, форми, картки, іконки та порожні/помилкові
стани. Візуально оглянуто [попередній розділ наборів](https://www.figma.com/design/K9H9c4FOZBzi3KgMQGYYMT/LMV_lab3?node-id=179-1755).
Збережено сині основні дії, світлі картки, постійні підписи полів і попередні макети.

## Готові екрани

`SmartBasket-html-to-design.html` — один документ із чотирма екранами:

1. Мої набори: лише назви, «Відкрити набір» та дії з набором.
2. Деталі набору: продукти, кількості, підсумок і редагування.
3. Додавання продукту: каталог і пошук.
4. Порожній список наборів.

Окремі HTML-файли та PNG-прев’ю також доступні. PNG призначені лише для
перегляду; імпортуйте HTML, щоб отримати текст і векторні елементи.
HTML не потребує запущеного сервера: CSS і Inter вбудовані, іконки — SVG.
Зовнішніх запитів під час перевірки експорту не було. Дані на екранах —
демонстраційні; збережені дані користувача не використовувалися.

## Імпорт у ваш файл

Ціль: https://www.figma.com/design/K9H9c4FOZBzi3KgMQGYYMT/LMV_lab3

1. Відкрийте файл і запустіть плагін **html.to.design**.
2. На вкладці **File** виберіть `SmartBasket-html-to-design.html`.
3. У параметрах увімкніть **Use Autolayout**, **Create styles & variables** та
   **HTML layer names**. За наявності відповідних стилів файлу можна застосувати
   **Use existing local styles**.
4. Для огляду всіх чотирьох екранів установіть ширину імпорту **2100 px**.
   Окремі HTML-файли можна імпортувати по одному на ширині 494 px; сам пристрій
   має 430 px. Зайве зовнішнє тло після імпорту можна прибрати.
5. Якщо плагін запитає відповідність шрифту, зіставте **Inter Variable → Inter**.
6. Перевірте текст, SVG, обрізання прокручуваного вмісту та стилі. Не видаляйте
   наявні ідеї до порівняння: повного аудиту всього файлу ще не виконано.

Основні переходи для прототипу: «Відкрити набір» → деталі; «До моїх наборів» →
список; «Додати продукт» → каталог. Статичний HTML не виконує операції React;
інтерактивний застосунок залишається в Next.js.
